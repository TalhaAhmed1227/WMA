# WMA - Waste Management Application

**WMA** is a mobile app designed to track and manage waste collection and disposal. It provides real-time updates, secure user authentication, and the ability to send notifications or data via email and links.

## 🚀 Features:
- **User Authentication**  
  Users can sign in and register using Firebase Authentication. Admin and User roles are supported for different levels of access.

- **Real-Time Database Updates**  
  Waste management data is stored in Firebase's Realtime Database, ensuring updates are reflected across devices immediately.

- **Notifications and Emails**  
  Sends notifications or data links via email using Firebase Cloud Messaging. Users can receive up-to-date waste management information instantly.

## 🛠️ Technologies Used:
- **Android Studio** (Java/Kotlin)
- **Firebase Authentication** (User & Admin authentication)
- **Firebase Realtime Database** (Real-time updates)
- **Firebase Cloud Messaging** (For sending data via email or links)
